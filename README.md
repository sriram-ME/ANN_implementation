# ANN_implementation
* Dataset choosen is related to customer database in bank.
* Based on ceratin parameters it surveyed whether a customer stays or exits the bank.
* Nerual networks with 11 inputs, 2 hidden layers and 1 output layer is coded.
* Rectified Linear Unit(ReLU) is used as activation function for input and hidden layers.
* Sigmoid function used as activation function in output layer.
* One hot encoding performed on categorical features.
* Train test split is done to segregate and retain the data for testing purpose.
* Nerual networks with sequential model and ADAM optimizer is used for training purpose.
* Early stopping and dropout concepts are implemented.
* Test data accuracy is predicted and accuracy score is calculated.
